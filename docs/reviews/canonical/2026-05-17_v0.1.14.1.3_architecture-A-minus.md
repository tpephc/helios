## Five additions identified

1. **§6.5 Signal Lifecycle State Machine** (critical, pre-impl) —
   without explicit transitions, v0.1.14.2 will invent them ad-hoc and ship ambiguity
   bugs at edges (what if exit fires while entry approval pending?)

2. **§7.5 Portfolio Philosophy** —
   currently portfolio frame is "risk control". F-experiment insight shows it's
   actually "alpha-preserving filter". Six principles: constraints filter quality,
   capital scarcity ranks, clustering is feature, sparseness is correct,
   underdeployment is OK, concentrated exposure can improve expectancy.

3. **§9 Escalation Policy** (critical, pre-impl) —
   v0.1.14.2 telegram code needs `input spec` for operator-unavailability cases.
   9-scenario table principles: "missed signal > wrong trade".

4. **§9 Market Calendar Semantics** —
   acknowledgment in arch (TWSE business days, holidays, typhoon closures, makeup
   workdays). v0.1.14.2 hardcoded calendar; v0.2+ TWSE API.

5. **§12 Roadmap Rule** —
   "No feature enters default workflow until: backtested → OOS validated →
   paper-traded → operationally observed". Research-valid ≠ operationally-safe.

## Reviewer's most important framing

> "Production readiness B grade is NOT fixable by more documentation. It only
> improves through operational scars accumulated during paper trading. Therefore

documentation polish has reached diminishing returns; ship paper trading next.
