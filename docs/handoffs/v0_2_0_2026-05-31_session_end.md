## 2. Core Decision: Exit Contract Defined

### Before This Session
```
production exit = undefined
run_exit_scan.py existed but RegimeExit/TrailingStop conditions
  never validated against entry thesis
TimeStop did not exist
tracker 20d return assumed to equal production strategy PnL
```

### After This Session
```
production exit = hybrid (3 rules, priority-ordered)
tracker 20d return = signal-quality gate (NOT strategy PnL)
closed-position PnL = strategy-quality gate (separate)
go-live requires BOTH gates to pass
```

**Exit contract v0.2.0:**
```
Priority 1: RegimeExit
  condition:  TAIEX regime == "bear"
  action:     full exit at next T+1 open

Priority 2: TrailingStop
  condition:  close <= max_close_since_entry - 2 * entry_atr
  action:     full exit at next T+1 open

Priority 3: TimeStop
  condition:  holding_trading_days >= 20
  action:     full exit at next T+1 open

Evaluation order: RegimeExit → TrailingStop → TimeStop
First trigger wins. exit_reason + full metadata logged to exit_audit table.
```

**Key design decisions and rationale:**

| Decision | Rationale |
|----------|-----------|
| RegimeExit bear-only (not != bull) | Crisis entries allowed for V-recovery thesis; exiting on crisis defeats the entry intent |
| TrailingStop uses entry_atr (not current) | Current ATR widens stop during volatility expansion = weakest protection when most needed; entry_atr is fixed, deterministic, auditable |
| TimeStop at 20 trading days | Bounded holding period; aligns with tracker 20d horizon as upper bound |
| Forced exit on missing data | P0 invariant: halted stocks cannot silently bypass max holding period; uses last available adj_close with full sell-side costs |
| exit_audit table | Self-contained metadata persistence; every exit (normal or forced) writes full rule parameters for strategy gate audit |

## 3. Core Decision: Dual Evidence Gate

### Before This Session
```
single gate: forward_return_tracker.py 20d fixed-horizon
assumed 20d return = production strategy outcome
```

### After This Session
```
Signal Gate:
  source:    forward_return_tracker.py
  metric:    20d fixed-horizon net return from T+1 open
  measures:  signal predictive quality
  criteria:  n>=150, mean>0, hit>52%, CI_lower>0, worst_month>=-2%

Strategy Gate:
  source:    closed positions (positions table, exit_audit)
  metric:    per-trade net return (actual exit, variable holding period)
  measures:  production strategy PnL under real exit rules
  criteria:  TBD (next session — n, mean, CI with appropriate method)

Go-live requires BOTH gates to pass.
```

**Rationale:** production exit (RegimeExit/TrailingStop/TimeStop) creates a
different return profile than fixed 20d hold.  A signal that shows +8% at
day 20 might have been stopped out at -4% on day 3.  Signal gate certifies
entry quality; strategy gate certifies exit-rule quality.  Divergence between
gates is diagnostic: signal gate passes + strategy gate fails = exits
destroying value.

## 4. Tracker Audit Findings (Code-Confirmed)

Full line-by-line audit of `forward_return_tracker.py` v0.2.0 completed.

### Confirmed P0 Issues

**P0-1: CI uses iid t-interval (L418-424)**
```python
ci_lower, ci_upper = sp_stats.t.interval(
    0.95, df=n-1, loc=mean_r, scale=std_r/np.sqrt(n)
)
```
Overlapping 20d windows + shared market factor → effective n << 150.
CI systematically too narrow → false positive (pass gate when no edge).
Fix: cluster-by-signal-date bootstrap.

**P0-2: Resolution silently drops missing-day signals (L297, L542, L555)**
```python
fully_resolved = len(price_series) >= MAX_HOLDING_DAYS  # L297
```
If a stock is halted on ANY of the 20 market trading days, `len(price_series) < 20`
→ never resolved → silently excluded from gate denominator.  Excluded signals are
disproportionately left-tail (bad outcomes) → survivorship bias re-enters through
the resolution criterion.
Fix: resolve based on elapsed trading days, not available price count.
Missing-day policy (user-approved):
```
1. normal halt:     last available adj_close, imputed_exit=true
2. delisting:       delisting reference price
3. no price at all: documented conservative haircut
4. all forced:      forced_resolved=true, counted in gate denominator
```
