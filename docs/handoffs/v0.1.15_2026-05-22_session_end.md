## Design Summary

State machine zones per position:
trailing_stop  = max_close_since_entry - 2.0 × entry_atr
approach_enter = trailing_stop + 0.5 × entry_atr
approach_exit  = trailing_stop + 0.8 × entry_atr
NORMAL → APPROACH: price ≤ approach_enter
APPROACH → NORMAL: price > approach_exit  (dead-band: 0.3×ATR)

→ BREACH:        price ≤ trailing_stop  (unconditional)
BREACH → APPROACH: trailing_stop < price ≤ approach_exit
BREACH → NORMAL:   price > approach_exit
Key guarantees:
- Notify only — positions table never written
- Outbox: DB COMMIT before Telegram send
- Idempotency: UPDATE...RETURNING (not SELECT-after-UPDATE)
- System alert isolation: bot failure does not interrupt position supervision
- System alert cooldown: 60 min
