## 3. Evidence Framework — Three New Scripts

### `research/forward_return_tracker.py` v0.2.0

**Purpose:** Record unbiased forward returns from all production signals.
Tracker = evidence recorder, not evidence generator. Forward paths for
signals already in `signals` table are extracted immediately.

**Data model:** one row per `(signal_id, holding_day)` in
`forward_return_observations` table.

**Key design:**
- All approval statuses included (APPROVED / TIMEOUT / EXPIRED_DRIFT / PENDING)
- Incremental update: re-runs fill missing days; `ON CONFLICT DO NOTHING`
- `resolved = True` only when full 20-day series is complete
- `strategy_version` + `tracker_schema_version = 1` prevent mixing versions
- Entry ref: T+1 `adj_open`; cost: 40 bps round-trip

### `research/bull_strategy_sanity_harness.py` v0.3.0

**Purpose:** Determine if strategy is CLEARLY BROKEN — not whether it has alpha.

**Verdict schema:**
```
FAIL         : mean < 0 AND CI upper < 0  (bias-robust; only actionable output)
INCONCLUSIVE : everything else             (including positive results)
[no PASS verdict exists]
```

**Baseline run** (`--start 2021-06-18 --oos-start 2025-01-01 --end 2026-05-29`):

| Subset | n | mean | CI upper | hit% | Verdict |
|--------|---|------|----------|------|---------|
| ALL OOS | 137 | +8.50% | +12.34% | 64.2% | INCONCLUSIVE |
| HIGH | 34 | +7.70% | +17.10% | 79.4% | INCONCLUSIVE |
| NORMAL | 103 | +8.76% | +12.92% | 59.2% | INCONCLUSIVE |
| bull | 115 | +6.05% | +9.78% | 59.1% | INCONCLUSIVE |
| crisis | 22 | +21.28% | n/a | 90.9% | INCONCLUSIVE (small_n) |

**FAIL not triggered. Strategy not ruled out.**

Crisis +21.28% is the most survivorship-biased subset (high-vol periods where
only V-recovery survivors remain). Do not use for decisions.

**Key design decisions:**
- Ranking mirrors `screener.py` exactly: `(priority ASC, dist ASC, -rs DESC)`
- No synthetic score
- `max_entry_gap_pct = 0.03` gap filter (mirrors production EXPIRED_DRIFT)
- `entry_slippage_bps = 5` (best-case; re-run with 20 for sensitivity)
- IS block hidden by default (`--verbose` to show)
- `breakout` screener is a stub — breakout trades not yet included

```python

bear:    close < sma_200 AND vol_20 <= 0.020
neutral: otherwise (SMA-200 transition)
```
