## 關鍵決策

**Signal event-keyed semantics（2026-06-02 拍板）**
Signals are event-keyed on (symbol, strategy, signal_type, signal_date).
Terminal states (REJECTED, EXPIRED_DRIFT, TIMEOUT) permanently close the
canonical signal event. A rerun of the same opportunity returns the
existing signal_id with created=False. New signal generation for the same
key is not permitted regardless of prior terminal state.
Rationale: Helios is a daily-batch T+1 system. signal_date represents the
trading opportunity date, not a generation timestamp. Re-generating a
REJECTED signal would split the event history and corrupt Forward Return
Tracker lineage.
