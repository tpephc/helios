## What Changed This Session

### v0.1.14.3.7 — Two production bugs fixed

**Bug A — Phantom approval via stale Telegram queue**
Scar (2026-05-18): operator's prior-session "Approve" sat unconfirmed in
Telegram's getUpdates queue. New listener started with offset=0, received
the stale message, `classify_command` resolved it onto fresh DEV-TEST-003
→ phantom APPROVED the operator never sent.

Fix: `_drain_pre_startup_updates(bot)` called at listener entry.
- `get_updates(offset=-1, timeout=0)` → peek last update
- `get_updates(offset=last_id+1, timeout=0)` → confirm-and-discard all
- Log: `listener_drained_pre_startup`
- File: `communication/telegram/listener.py`

**Bug B — `_check_atr_drift` no-price path returned False (reject)**
Scar: no-ATR path returned `(True, "跳過")`. No-price path returned
`(False, "無法驗證漂移")`. Both are "cannot verify" — opposite semantics.
No-price fires on every intraday approval before ~15:00 EOD sync.

Fix: no-price path now returns `(True, "...跳過漂移檢查")`.
- Log: `approval_drift_check_skipped_no_price`
- File: `execution/approvals.py`

**Supporting changes:**
- `MockTelegramBot`: faithful offset semantics (`offset=-1` peeks without
  confirming; monotonic `_next_update_id`; `on_poll` hook for post-drain
  message injection in tests)
- `test_unauthorized_chat_ignored`: migrated to `on_poll` hook (pre-seed
  would be drained away)
- 2 new invariants in `tests/invariants/test_semantic_invariants.py`:
  `test_listener_does_not_consume_pre_startup_telegram_updates` (3 assertions:
  no phantom approve, signal stays PENDING, queue actually drained) and
  `test_check_atr_drift_returns_true_when_no_price_data_for_fill_date`
- Tests: 71 → 73 passed

### v0.1.14.3.8 — `--bootstrap-price` flag

Scar: `PaperBroker.submit_buy` reads `daily_price_adj[fill_date]` for
adj_open (ref_price) and volume (liquidity gate). Before EOD sync (~15:00),
both fail → `paper_fill_failed: no_volume_data`.

Fix: `scripts/dev_push_signal.py`:
- `--bootstrap-price`: injects synthetic `daily_price_adj` row via
  `INSERT OR REPLACE` before pushing signal. EOD sync overwrites.
- `--bootstrap-volume INT`: synthetic volume (default 25,000,000).
- `_bootstrap_price_row`: sets adj_open=adj_close=price, cum_factor=1.0.
  Drift against itself = 0 → drift gate passes.
- New test: `test_bootstrap_price_enables_broker_fill`
- Tests: 73 → 74 passed

## Architecture Decisions (this session)

**Drain-first listener**: `listen_for_approvals` always drains on entry.
Any future restart path (e.g., `run_listener_only.py`) must call through
`listen_for_approvals`, not bypass it.

**Permissive "cannot verify"**: both no-ATR and no-price exits in
`_check_atr_drift` return `(True, skip)`. Intraday approval before EOD sync
is a normal operating condition. PaperBroker is the last safety gate.

**`--bootstrap-price` is dev-only**: `_bootstrap_price_row` called only from
`dev_push_signal.py`. No `if DEV_MODE` in production paths.

**HEREDOC for small doc edits**: prefer `cat > file << 'EOF'` or `python3 -c`
on nexus directly for doc-only changes; reserve tar+scp for code changes.

**Packaging**: plain `.tar` (no compression). Update Settings → Profile.
